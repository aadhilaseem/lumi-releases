# Anova — app downloads

Anova (formerly LUMI) is a private life-assistant Android app. This page only hosts the app file for downloads and in-app updates — no source code, no personal data.

**Install:** open [Releases](https://github.com/aadhilaseem/lumi-releases/releases/latest) on your phone → download `Anova.apk` → open it → allow "Install unknown apps" if asked.

After that, Anova updates itself: when a new version is out, the app shows **"New version available"** → tap **Update**.

You need your own free Gemini API key (aistudio.google.com). Your data stays on your phone.
